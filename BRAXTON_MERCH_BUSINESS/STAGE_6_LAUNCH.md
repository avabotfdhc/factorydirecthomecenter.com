### 30.2 Password Removal

#### Steps:
```
1. Shopify Admin > Online Store > Preferences
2. Scroll to "Password protection"
3. Uncheck "Enable password"
4. Save
5. Verify site loads without password
```

## Troubleshooting Common Issues

### Issue: Site won't load after password removal
**Solution:** Clear browser cache, check DNS propagation (can take 24-48 hours)

### Issue: Checkout not working
**Solution:** Verify payment gateway is active, test in incognito mode

### Issue: Images not loading
**Solution:** Check image URLs, verify CDN status, re-upload if needed

### Issue: Emails not sending
**Solution:** Check spam folders, verify sender email, test SMTP settings

### Issue: Slow site speed
**Solution:** Compress images, remove unused apps, enable lazy loading
