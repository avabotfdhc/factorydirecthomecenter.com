### Common Issues

**Gateway not responding**
```bash
openclaw gateway status
openclaw gateway restart
```

**Cron job failing**
```bash
openclaw cron list
openclaw cron runs <job-id>
```

**Memory not syncing**
```bash
# Check qmd status
qmd status
# Rebuild index
qmd rebuild
```
