# Lead Generation System

### Target Audience
- **Primary**: First-time manufactured home buyers (30-55)
- **Secondary**: Downsizers, retirees (55+)
- **Tertiary**: Investors, landlords

### Geographic Focus

- Michigan, Ohio (secondary)
- Illinois, Kentucky (tertiary)

## Lead Magnets

### 1. Manufactured Home Buyer's Guide
**Format**: PDF download
**Content**: 10-15 pages covering process, financing, FAQs
**Gate**: Name, email, phone

### 2. Financing Calculator
**Format**: Interactive web tool
**Features**: Monthly payment estimator, down payment options
**Gate**: Email for results

### 3. Model Comparison Tool
**Format**: Interactive comparison
**Features**: Side-by-side specs, pricing, availability
**Gate**: Optional (lead gen vs. utility)

### 4. Free Consultation
**Format**: Calendar booking
**Value**: 30-min call with Kyle
**Gate**: Qualification questions
