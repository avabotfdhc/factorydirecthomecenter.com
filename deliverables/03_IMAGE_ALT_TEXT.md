## Technical Image Optimization

### File Naming Convention

**Current:** `IMG_1234.jpg` ❌

**New:** `champion-[model]-[view]-[descriptor].jpg` ✅

**Examples:**
```
champion-brighton-exterior-front.jpg
champion-dutch-aspire-1656h22208-living-room.jpg
champion-silverton-kitchen-island.jpg
fdhc-showroom-auburn-indiana.jpg
```

---

### Image Compression Requirements

**Format:** WebP (with JPEG fallback)
**Quality:** 80-85%
**Max Dimensions:** 1920px width (largest display size)
**File Size Target:** Under 200KB per image

---

### Image Dimensions by Use

| Location | Width | Height | Aspect Ratio |
|----------|-------|--------|--------------|
| Hero/Header | 1920px | 600px | 3.2:1 |
| Floor Plan Cards | 600px | 400px | 3:2 |
| Floor Plan Detail Hero | 1200px | 800px | 3:2 |
| Gallery Thumbnails | 400px | 300px | 4:3 |
| Gallery Full | 1600px | 1200px | 4:3 |
| Blog Featured | 1200px | 630px | 1.91:1 (social) |

---

### Lazy Loading

Add `loading="lazy"` to all images below the fold:

```html
<img src="champion-brighton-exterior.jpg" 
     alt="Champion Brighton sectional exterior — 3 bed 2 bath double wide manufactured home Auburn Indiana"
     loading="lazy"
     width="600"
     height="400">
```

---

### Responsive Images

Use `srcset` for different screen sizes:

```html
<img src="champion-brighton-600.jpg"
     srcset="champion-brighton-400.jpg 400w,
             champion-brighton-600.jpg 600w,
             champion-brighton-1200.jpg 1200w"
     sizes="(max-width: 600px) 400px, (max-width: 1200px) 600px, 1200px"
     alt="Champion Brighton sectional exterior — 3 bed 2 bath double wide manufactured home Auburn Indiana">
```
