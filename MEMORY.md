## Technical Learnings

### Schema Implementation
- 11 schema types now standardized across site
- LocalBusiness with geo coordinates essential for local SEO
- FAQPage schema drives AI search visibility
- Product schema per home enables rich snippets

### AEO (Answer Engine Optimization)
- Question-based H2/H3 headers perform best
- 40-60 word self-contained answers optimal for AI search
- 80+ FAQs across site creates comprehensive coverage

### Image Generation Best Practices
- Nano Banana Pro (Gemini) produces high-quality real estate images
- 2816x1536 resolution standard
- Proper alt tags critical for accessibility and SEO

### DMS Architecture
- Next.js 14 + Supabase + TypeScript stack proven effective
- Protected routes with middleware for security
- Row Level Security (RLS) essential for multi-user access
- Component library approach speeds development

### Domain Security
- WHOIS last-updated dates indicate compromise timing
- Backup domain strategy (.com, .net, .org) critical for business continuity
- Multiple extension registration prevents brand hijacking

### Security Protocols
- Investment solicitations: verify registration numbers (FINRA/SEC)
- Cross-reference contact info with official company websites
- LinkedIn verification and reference checks standard procedure

1. **Git discipline matters** — Pull-before-push prevents merge conflicts
2. **Structured data is competitive advantage** — Most competitors lack proper schema
3. **AI images fill gaps** — Good for launch; real photos needed for trust
4. **AEO is the new SEO** — Answer engines (ChatGPT, Perplexity) require different optimization
5. **Batch work wins** — 50 images in one session beats one-at-a-time
6. **Subagent timeouts don't mean failure** — Parallel completion while subagent runs
7. **Domain security requires monitoring** — WHOIS changes indicate potential compromise
8. **Investment solicitations need verification** — Trust but verify with registration checks
9. **Tool parameter quirks need documentation** — Prevents repeated errors
10. **Cron jobs need free models** — nvidia/llama-3.1-nemotron-70b works well for scheduled research
11. **Analytics must be environment-aware** — Only deploy tracking IDs to production when ready
12. **Purchase agreements require source documents** — Cannot build legally sound contracts without original language
13. **Verify all pricing calculations** — Spot-check formulas before sending; 185% vs 65% markup is a costly error
14. **Storm damage documentation** — Photo evidence expedites permits and insurance claims
